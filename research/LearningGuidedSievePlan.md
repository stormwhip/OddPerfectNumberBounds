# 学习引导的容斥多项式搜索：研究方向与实施计划（V1.0）

更新日期：2026-11-16

## 1. 研究定位

项目名称：**Learning-Guided Search for Certified Sieve Majorants**（LG-CSM，学习引导的可认证筛函数上界搜索）。

目标是在受限奇完全数（restrained odd perfect number）的指数下界问题中，自动寻找**可以被独立、精确验证**的容斥多项式，进一步提高指数 q 的严格下界。数学结果与机器学习算法贡献分别考核。

现有成果来自**确定性搜索**，并非机器学习训练成果：采用原论文的 n=3 归约、小素数排除及 Lemma 8，仓库最初用分段筛和解析尾部界证明 q>7.705×10^19；新的 12 素数、97 项容斥证书在相同有限筛数据上证明 **q>2.193×10^20**。可运行 \`python QBoundVerifyOptimized.py\` 复核，参见 [更新的研究报告](../ResearchReport.md)。

## 2. 数学抽象

给定已被严格排除、不能整除所研究奇完全数的素数集合 P，对每个候选素数 r 定义
\(I_\ell(r)=[\ell\mid r^2+r+1]\in\{0,1\}\)。
要为通过全部筛选的素数构造逐点上界

\[
G_a(z)=\sum_{S\in\mathcal M}a_S\prod_{\ell\in S}z_\ell,
\quad G_a(z)\ge \mathbf 1_{\{z=0\}}\quad(\forall z\in\{0,1\}^{|P|}).
\]

单项式池 \(\mathcal M\) 受显式素数计数定理的可用模数限制。令 \(m_S=\prod_{\ell\in S}\ell\)。初始实验仅选 \(m_S\le10^4\) 的合法交集，并使用当前验证程序中的误差因子。其主项密度为
\(d_S=\prod_{\ell\in S}2/(\ell-1)\)，因此

\[
\delta(a)=\sum_S a_Sd_S,\qquad
C(a)=\sum_S|a_S|e(m_S),
\]

其中已验证的初始域内 \(e(m_S)=2^{|S|}/840\)；扩展模数时必须重新检查适用的定理及其误差常数。**每一个候选多项式都必须满足逐点非负约束**，随后经过有理数证书校验。

固定分段筛终点 B、截断 Z 和目标 q 时，最终上界对 \(\delta,C\) 线性：优化
\(\min_a A(B,Z)\delta(a)+D(B,Z)C(a)\)，其中 A、D 从严格积分估计中计算。将 \(|a_S|\) 线性化为辅助变量，得到 LP。最终目标是对 Z 与 q 联合搜索，最大化**可认证的 q**，而非单独最小化 \(\delta\)。

## 3. 算法设计

**阶段 A：精确确定性基线。**

1. 将现有多项式、布尔状态、\(\delta,C\)、积分上界、有限筛数据整合为独立的证书格式（JSON + Fraction）。
2. 实现小规模全池 LP（SciPy/HiGHS）、贪心选项、随机选择和**不含机器学习**的列生成。
3. 采用 constraint generation：先解部分状态约束，再寻找 \(G_a(z)<\mathbf 1_{\{z=0\}}\) 的反例并加入 LP。小规模全部 \(2^{|P|}\) 状态穷举，大规模由 0–1 MILP 分离器实现。
4. 浮点 LP 的候选有理数重构后，统一交给独立验证器审核。每次验证输出精确的最差余量和使用的定理适用域。

**阶段 B：学习引导的候选单项式选择。**

将允许的候选单项式作为待选择的“列”，在受限 LP 每轮迭代时由学习策略挑选最有前景的 k 项加入模型。建议从监督学习排序/上下文 bandit 起步，之后再考虑强化学习。学习模型只负责**搜索速度与启发式排序**，完全不参与证明步骤。

特征：单项式阶数、\(\log m_S\)、主项贡献 \(d_S\)、误差代价 \(e(m_S)\)、当前 LP 的 reduced cost（可得时）、约束违反程度、当前证书余量、B/Z 的数值尺度。先用梯度提升或小型 MLP，再测试图神经网络/Set Transformer 编码素数与交集超图。

监督标签：在同一时间或候选列预算下，一轮选列导致的 LP 目标下降、到达下一个**严格认证** q 的总搜索成本。离线训练样本来自确定性基线与多组 P/模数预算实例，避免模型先看到测试实例的搜索轨迹。

**阶段 C：联合参数搜索。**

对 P、合法单项式、Z、目标 q 实行分层优化；外层采用网格/贝叶斯优化（固定随机种子），内层使用 LP/学习引导列生成。B 的扩大需要重新执行 C++ 分段筛，计算成本必须单独计入。

## 4. 必做实验与对照组

| 方法 | 使用学习模型 | 对照意义 |
|---|---|---|
| 固定人工容斥公式 | 否 | 原始证书与 97 项新证书 |
| Random legal columns | 否 | 随机策略 |
| Greedy / reduced-cost | 否 | 简单规则 |
| Full LP（小实例） | 否 | 最优解参考 |
| Constraint/column generation | 否 | 强确定性基线 |
| Learning-guided column generation | 是 | 拟研究方法 |

核心指标为**固定墙钟时间、固定 LP 调用次数或单项式预算下可严格认证的最大 q**；辅助指标包括首次找到指定 q 的时间、证书项数、最大模数、违例状态数量、精确核验成功率和多随机种子方差。

训练/验证/测试需要按 **P 集合和模数预算的实例**分割；同一实例的 Z/q 轨迹必须属于同一数据分区。报告已见规模、全新 P 集合和扩大规模三组结果，并与强非学习列生成做成对比较。

消融：移除 reduced-cost 特征、移除超图编码、不同搜索奖励、固定 Z 对比联合搜索、移除学习排序。保留 ML 无优势的失败实验记录，以检验学习模块的必要性。

## 5. 六周实施顺序

| 周 | 交付物及可量化验收 |
|---|---|
| 1 | 证书 JSON 规格、纯 Python 精确验证器；复算 q>2.193×10^20；为当前多项式生成可审查的测试 |
| 2 | LP 与布尔分离器；在 |P|≤12 上与穷举/已有公式交叉校验，记录对偶界 |
| 3 | 无学习的列生成、贪心、随机基线；固定种子实例集及训练/测试分割 |
| 4 | 轻量监督排序模型；在完全相同搜索预算下和强基线比较 |
| 5 | 扩展至更大 P、更多合法模数；与外层 Z/q 参数优化结合，导出更强的可验证证书 |
| 6 | 完整审计、重现实验、误差与失败案例、数论与 ML 两部分写作 |

## 6. 成功判据与研究风险

数论成功：在原有计算数据或独立扩展筛的基础上，得到**严格更大的 q 下界**，并公开证书、验证器、编译命令、随机种子和原始结果。

机器学习成功：在未见过的 P/预算实例上、固定资源下，学习引导方法显著优于贪心与无学习列生成；模型若仅重复 LP 的结论，应按“无可测增益”报告。

优先检查：现有 LP 是否已足够快速；误差绝对值项是否压过低密度收益；大模数所需的解析数论定理是否实际可用；完整 4943 行 C++ 有限筛数据是否能在另一台机器上全量重算。公开论文时应区分当前确定性证书与未来 ML 实验。

## 9. 首轮试验记录（2026-11-16，已完成）

首轮实验已实际训练 LightGBM，结果见 [PilotReport.md](experiments/PilotReport.md)，代码分别为 [学习引导实验](experiments/learning_guided_pilot.py) 与 [完整 LP 基线](experiments/lp_full_search.py)。

- 纯 LP 在固定 Z 的 12/13 素数合法多项式池内找回当前 97 项证书，数值最优；该实验没有增加 q 的严格下界。
- LightGBM 四组独立随机种子、每组 60 训练与 20 测试实例、每例限选 5 个三次项，平均取得完整 LP 目标改善的 72.70%；确定性规则为 75.06%，随机策略为 54.49%。
- 本次 ML 实验已完成并可复现，**模型尚未超过强确定性基线**。数论界仍由 QBoundVerifyOptimized.py 中的精确证书确定。

**计划调整**：下一阶段先构造超出现有 99–244 单项式规模的难实例、加入高阶交集与非均匀误差系数，再比较有学习和无学习的列生成算法。优先改善问题的搜索复杂性和评价设计，不把分类 AUC=1 作为发现新数学结果的依据。
