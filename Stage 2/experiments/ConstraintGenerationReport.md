# 约束生成基线探索（2026-11-16）

本轮属于 **Stage 2 的数值线性规划实验**，完全不使用 ML，未产生新的严格数论下界。

研究策略：从与每个合法非空单项式对应的布尔状态开始形成一个小 LP；求解后在完整布尔状态空间中寻找 G(z)<0 的违反约束状态，将最坏的若干状态加回 LP，重复直至没有违反约束的状态。固定 B=5.029×10^13、Z=5.74335×10^22、模数≤10^5、次数≤4、与前期实验相同的误差费用。

| 素数数目 | 全部布尔约束 | 初始且最终活动约束 | 轮数 | 总用时（本地） | 数值结果 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 12 | 4,095 | 213 | 1 | 0.06 秒 | 原有 97 项多项式 |
| 15 | 32,767 | 309 | 1 | 约 0.27–0.40 秒 | 原有 97 项多项式 |
| 16 | 65,535 | 339 | 1 | 0.51 秒 | 原有 97 项多项式 |

全部测试在首次小 LP 结束后完整检验了所有布尔状态，均未发现违例；最终数值目标约 0.193888368094804，δ≈0.382912145497930，C≈0.515476190476190。与 [完整 LP 实验](ExtendedSearchReport.md) 的最优数值目标一致。运行时间依赖机器，本轮的 Python 构造、求解与验证均计入用时。

**判断**：对于现有合法单项式池，确定性的活动约束选择已经大幅减少 LP 求解规模，学习引导约束选择需要在真正需要多轮生成的困难实例中才能建立优势。现有结果也提示，进一步改进 q 需要探索新的合法筛权、尾部解析不等式或有限筛信息的利用方式。

复现：

```bash
python "Stage 2/experiments/constraint_generation.py" --primes 12
python "Stage 2/experiments/constraint_generation.py" --primes 15
python "Stage 2/experiments/constraint_generation.py" --primes 16
python "Stage 1/QBoundVerifyOptimized.py"
```

前三个命令输出浮点 LP 目标与布尔枚举校验结果；最后一个命令独立核验 Stage 1 的严格数论下界。实验代码仅需 numpy、scipy，不使用第三方 API 或付费模型。
